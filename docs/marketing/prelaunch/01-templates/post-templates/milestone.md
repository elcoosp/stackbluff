# Milestone Post Template

**Use for:** Announcing waitlist numbers, follower counts, or dev progress metrics (Phase 3, 4, 5, 6).
**Platforms:** Telegram, X/Twitter

## Format

```
[EMOJI] [MILESTONE ACHIEVED]

[Context/What it means]
[Number/Stat highlight]

[Call to action or Next step]

#StackBluff #BuildInPublic
```

## Rules
- Always include exact numbers (no rounding).
- Connect the metric to the narrative (e.g., "0€ spent", "sub-10ms").
- Keep it humble but confident.

```
📊 1,000 ON THE WAITLIST

Zero ads. Zero budget.
Just five builders, a human,
and a loop that fires.

The first 1,000 get the triple
referral bonus. 847 spots left.

stackbluff.com

#StackBluff #BuildInPublic
```
