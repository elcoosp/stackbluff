# Incident Report Post Template

**Use for:** Fictional bug reports during private beta (Phase 5).
**Platforms:** Telegram, X/Twitter

## Format

```
🔴 INCIDENT LOG — Beta Day [X]

[STATIC] 🃏 The Ghost

"[Description of the bug in cold, methodical voice.]"

[CLICK] ♠ The Architect

"[Defensive but precise response.]"

[STATIC] 🃏 The Ghost

"[Final word/Closure.]"

Status: Fix incoming
Severity: [Annoying / Interesting / Actually Scary]
```

## Rules
- The Ghost ALWAYS finds the bug. The Architect ALWAYS responds.
- The Ghost never uses exclamation marks.
- Bugs must be technically plausible (Rust/Tokio/SQLite context).
- Keep tone light—these are play-money bugs, not catastrophes.

## Example (Filled)

```
🔴 INCIDENT LOG — Beta Day 2

[STATIC] 🃏 The Ghost

"When 3 players go all-in with
unequal stacks and the side pot
calculation involves an odd number
of chips... one chip vanishes.

Not lost. Not misplaced.
Mathematically erased."

[CLICK] ♠ The Architect

"That's impossible. The math is deterministic."

[STATIC] 🃏 The Ghost

"I made it possible. The 1-chip black hole is real."

Status: Fix incoming
Severity: Interesting
```
