# Crew Log Post Template

**Use for:** All standard builder updates (Phase 1, 2, 3, 4, 5).
**Platforms:** Telegram, X/Twitter

## Format

```
[SOUND_TAG] · Day [XX]

[Line 1 of text - Max 80 chars]
[Line 2 of text - Max 80 chars]
[Line 3 of text - Max 80 chars - Optional]
[Line 4 of text - Max 80 chars - Optional]

[SYMBOL] (Only if Phase 2+)
```

## Rules
- Sound tags: `[CLICK]` (Architect), `[SWISH]` (Canvas), `[CHIME]` (Diplomat), `[RUSH]` (Catalyst), `[STATIC]` (Ghost), `[VOICE]` (Human).
- Max 4 lines of body text.
- Max 80 characters per line (for image card rendering).
- The Ghost NEVER uses exclamation marks.
- The Architect always uses precise numbers.
- No hashtags in Phase 0 or 1. #StackBluff allowed from Phase 3+.
