# Signal Intercept Post Template

**Use for:** Reposting community reactions/speculation without confirming or denying (Phase 2 & 3).
**Platforms:** Telegram, X/Twitter (Quote Tweet)

## Format

```
📡 SIGNAL INTERCEPT

"[User comment/theory 1]"
— @[username1]

"[User comment/theory 2]"
— @[username2]

"[User comment/theory 3]"
— @[username3]

We neither confirm nor deny.
But we are watching.
```

## Rules
- Only use real, public comments from the community.
- Never change the meaning of the user's quote.
- Never confirm or deny the theory.
- Keeps the mystery alive while validating community engagement.
