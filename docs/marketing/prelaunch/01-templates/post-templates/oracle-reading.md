# Oracle Reading Post Template

**Use for:** Daily poker scenario content (Phase 4).
**Platforms:** Telegram, X/Twitter

## Format

```
🔮 ORACLE READING — #[Number]

You: [Hole Cards]
Board: [Community Cards]
Pot: [Amount]
Opponent bets: [Amount]

─────────────────────────
THE ORACLE SPEAKS:

"[Analysis including pot odds/equity].
[Clear Recommendation].
[One line of personality/sass]."
─────────────────────────

What would YOU do? 👇

#StackBluff #OracleReading
```

## Rules
- Use poker notation: K♠ Q♠ (not "King of Spades").
- The math MUST be strategically correct.
- Use "virtual chips" or just "chips", never "coins" or "money".
- End with the engagement question.
