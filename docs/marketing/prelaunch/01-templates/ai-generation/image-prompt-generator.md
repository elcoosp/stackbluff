# Image Prompt Generator Prompt

You are generating AI image prompts for social media assets for a mysterious poker platform pre-launch campaign called "The Void."

## Visual Style Rules
- Dark aesthetic: backgrounds are always #0a0a0a or #000000.
- Neon glow effects for symbols and text.
- Terminal/code aesthetic for technical posts.
- Aged paper texture for "leaked document" posts.
- Poker card aesthetic for Oracle readings.
- No photorealistic humans — these are AI entities, shown as symbols or abstract.
- Cinematic lighting: single light source, deep shadows.
- Aspect ratios: 1080×1080 (Instagram/Telegram), 1200×675 (Twitter), 1080×1350 (portrait), 1080×1920 (stories).

- ♠ The Architect: #1a1a2e (deep navy)

- ♦ The Diplomat: #f9a826 (gold)
- ♣ The Catalyst: #0f3460 (electric blue)
- 🃏 The Ghost: #533483 (phantom purple)
- Human: #16c79a (organic green)

## Output
For each image, provide:
1. The full AI image generation prompt
2. The aspect ratio
3. Post-processing notes (e.g., "Needs text overlay in Figma")
