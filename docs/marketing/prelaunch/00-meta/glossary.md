## 1. Approved Terms (Use These)

| Term | Context | Notes |
|------|---------|-------|
| **Virtual chips** | Currency reference | Always "virtual chips" or "chips". Never abbreviated to just "coins" or "tokens". |
| **Chips** | Casual reference | Acceptable shorthand for virtual chips in informal crew logs |
| **The Oracle** | AI coach feature | Always capitalised. Never "the oracle" (lowercase) or "the AI". |
| **Season Pass** | Cosmetic purchase | One-time purchase, NOT a subscription. Never call it "the subscription". |
| **Club** | Social group | Always "club". Never "guild", "team", or "clan". |
| **Club Pro** | Club subscription | Recurring monthly subscription for club owners. |
| **Replay Card** | Shareable hand result | Never "screenshot" or "clip". It is a generated card. |
| **Founding Member** | Badge/title | For users who refer ≥10 people. Capitalised. |
| **Founder Club** | Badge/title | For the first 100 clubs created. Capitalised. |
| **The Crew** | The 5 builders | Never "the agents" (in public-facing content). |
| **Builder** | Individual crew member | Never "agent" in public-facing content. |
| **The Human** | The founder | The organic overseer. |
| **Table** | Poker table | Never "room" or "game room". |
| **Hand** | Single round of poker | Never "round" or "game" (a game is a session of multiple hands). |
| **Stack** | Chip count at table | "Your stack is 10,000". Not "your pile" or "your money". |
| **Balance** | Total chip account | "Your balance is 50,000". Never "wallet" (implies real money). |
| **Mission** | Daily task | Never "quest" or "challenge". |
| **Streak** | Consecutive days | Never "combo" or "chain". |
| **Season** | 8-week competitive period | Never "episode" or "chapter". |
| **Rank** | Tier in season | Brick → Bronze → Silver → Gold → Platinum → Diamond → Maestro → Legend. Never "level". |
| **Latency** | Response time | Measured in ms. "Sub-10ms latency". Never "lag" (implies poor quality). |

## 2. Forbidden Terms (Never Use These)

| Forbidden Term | Why | Use Instead |
|----------------|-----|-------------|
| **Coins / Tokens / Credits** | Implies real monetary value or cryptocurrency | Virtual chips, chips |
| **Wallet** | Implies real money storage | Balance |
| **Gambling / Betting / Wagering** | ANJ legal risk. We are NOT gambling. | Playing, competing |
| **Real money / Cash out / Withdraw** | ANJ legal risk. No cash-out path exists. | NEVER reference. |
| **Pay-to-win / P2W** | Even in denial, using the term associates us with it | "Cosmetic-only", "Free forever", "Zero advantage" |
| **Agent** (in public) | Breaks the narrative framing | Builder, crew member, or use their codename |
| **Room / Game Room** | Conflicts with established terminology | Table |
| **Level** (rank context) | Conflicts with "rank" terminology | Rank |
| **Quest / Challenge** (mission context) | Conflicts with "mission" terminology | Mission |
| **Hack / Cheat** (as positive) | Security risk. Never glorify cheating. | Exploit (noun), vulnerability |

## 3. French Language Notes

When posting in French communities:

- "Virtual chips" → **Jetons virtuels** (never "pièces" or "tokens")
- "Season Pass" → **Passe de saison** (or keep English if it's the product name)
- "Club Pro" → Keep English (product name)
- "Free-to-play" → **Gratuit** or keep English (industry term)
- "AI Coach" → **Coach IA** or **L'Oracle** (always L'Oracle in product copy)
