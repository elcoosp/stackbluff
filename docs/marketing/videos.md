# 🎬 THE FACELESS PRODUCTION TOOLKIT

Before we dive into the videos, here is how you make a screen recording look like a $10k production:
1. **ElevenLabs Voices:** Create 3 distinct AI voices.
   * *Voice 1 (The Narrator):* Deep, calm, authoritative (like Morgan Freeman or a movie trailer guy).
   * *Voice 2 (The Player):* Slightly higher energy, used for inner monologues during poker hands.
   * *Voice 3 (The Oracle):* Cold, robotic, futuristic.
2. **CapCut Keyframing:** Never just show a static screen. Set a keyframe at the start of a clip to zoom in slowly, and another at the end to zoom out. This makes a static webpage feel cinematic.
3. **Sound Design (Crucial):** Since there is no face, audio carries the emotion. Use low bass rumbles for tension, sharp card "flicks" for dealing, and digital "swooshes" for UI transitions.

# 🚀 THE "INFINITE CONTENT" ENGINE (Post-Launch)

To sustain this for months, you need a system that generates videos for you automatically.

**Step 1: Build a "Replay Mode" Route**
Since you archive every hand as JSON to Cloudflare R2, build a hidden route in your React app (e.g., `/replay/:handId`). Feed the JSON into your existing `TablePage` components, but instead of real-time, it plays back step-by-step.

**Step 2: Query the Drama**
Write a script to query your database every Sunday for:
*   The biggest pot won.
*   The worst bad beat (highest % pre-flop that lost).
*   The biggest bluff (won a pot with 0% equity at the river).

**Step 3: Batch Produce**
Take those 3 hands. Screen record them in Replay Mode. Spend 2 hours on Sunday adding voiceovers and editing. You now have 3 videos for the week. 

Because you are faceless, you never have to worry about lighting, how you look, or retakes. The UI is the star, and the drama of the game does the heavy lifting.
